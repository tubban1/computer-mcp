# Computer MCP 1.0.4

Computer MCP 1.0.4 turns the macOS release into a single self-contained ChatGPT desktop-worker installer.

## Bundled OpenAI Tunnel Client

The package now includes OpenAI Tunnel Client v0.0.15 from the official `openai/tunnel-client` GitHub release.

- arm64 asset: official `tunnel-client-runtime-v0.0.15-darwin-arm64.zip`
- x64 asset: official `tunnel-client-runtime-v0.0.15-darwin-amd64.zip`
- upstream SHA-256 is pinned and verified during packaging
- upstream LICENSE, NOTICE, third-party license report, SPDX metadata, source URL, and checksum provenance are retained in the distribution
- no Tunnel ID or API key is ever embedded in the package

OpenAI Tunnel Client is distributed under Apache-2.0.

## First-run tunnel setup

The installer installs the bundled tunnel runtime under the versioned local runtime tree and points Computer MCP's existing tunnel configuration at it.

If a Tunnel ID and API key already exist, they are reused without prompting. Otherwise the first install asks for:

- Tunnel ID
- OpenAI API key, with hidden terminal input

The API key is stored in a mode-0600 local secret file and passed to Tunnel Client through its native `file:/path` secret reference. It is not written in plaintext to the launchd plist or Git repository.

## Unified automatic startup

After install, three supervised components start automatically:

- Computer MCP Runtime Server
- OpenAI Tunnel Client
- Computer MCP Helper

Runtime Server and Tunnel use launchd `RunAtLoad + KeepAlive`. Helper now also has its own launchd service running the stable signed Helper app executable in `--serve` mode.

Existing stable Runtime Host and Helper apps are preserved in place so macOS permission grants survive ordinary Server updates.

## Self-contained macOS package

The target Mac does not need Node.js, npm, TypeScript, Homebrew, a source checkout, or a separate Tunnel Client download.

The release contains:

- stable Computer MCP Runtime.app
- stable Computer MCP Helper.app
- official Node.js runtime
- official OpenAI Tunnel Client runtime
- compiled Computer MCP Server
- production-only npm dependencies
- installer and SHA-256 checksum

## Compatibility

Primitive ABI v1, Skill ABI v1, Session Adapter v1, Embedding Provider v1, Workspace Lease v1, state schema, Runtime Host identity, and Helper identity remain unchanged.

The long-duration 2h/6h/24h soak profiles remain available but are not claimed as completed evidence unless an observed run reports success.
