# Computer MCP 1.0.3

Computer MCP 1.0.3 closes the protected-folder hang found during real ChatGPT/Tunnel dogfooding on macOS.

## Fix

The 1.0.2 filesystem preflight checked protected paths with metadata-only `stat`. macOS can allow metadata access while a later directory enumeration or file read is still blocked by TCC, which could consume Node/libuv filesystem workers and eventually make both MCP calls and `/health` time out.

1.0.3 changes the default macOS preflight to an isolated child Node process that performs the same class of real I/O before the main Runtime touches the path:

- directories: `stat + opendir + read one entry`
- files: `stat + open + read one byte`
- the probe is killed after a bounded timeout
- the main Runtime receives `MACOS_FILE_PERMISSION_REQUIRED` instead of entering a blocked filesystem call
- allowlist rejection still happens before any probe

## Real protected-path evidence

A candidate launched from the actual packaged `Computer MCP Runtime.app`, bundled Node runtime, and bundled Server payload was tested against:

- `~/Desktop`
- `~/Downloads`
- `~/Documents`

On the current machine, all three correctly returned `MACOS_FILE_PERMISSION_REQUIRED` in about 0.77 seconds while the Runtime remained responsive. Immediate post-probe `/health` responses completed in roughly 5–23 ms.

The deterministic timeout verifier also passes repeatedly at about 155 ms with the event loop remaining responsive.

## Self-contained macOS distribution

The macOS release package now contains the complete Computer MCP core rather than only the permission-bearing host app:

- stable `Computer MCP Runtime.app`
- stable `Computer MCP Helper.app`
- official Node.js v24.21.0 runtime for the target architecture
- compiled Computer MCP Server
- production-only npm dependencies
- installer, README, and SHA-256 checksum

The target Mac does not need Node.js, npm, TypeScript, Homebrew, or the source repository. Separate arm64 and x64 packages are produced and both pass an isolated boot test using only the bundled Node runtime. Secure MCP Tunnel remains a separate external ChatGPT connectivity component and is not redistributed in the public package.

## Compatibility

No Primitive ABI, Skill ABI, Session Adapter, Embedding Provider, Workspace Lease, state schema, Native Helper identity, or Runtime Host identity changes are introduced.

The macOS distribution package still includes the same stable `Computer MCP Runtime.app` identity and the official Computer MCP icon.

## Qualification note

The 2-hour, 6-hour, and 24-hour soak profiles remain available but are not claimed as completed evidence unless an observed run reports success.
