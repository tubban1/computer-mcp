# Computer MCP 1.0.0

Computer MCP 1.0.0 is the first frozen production release of the standalone personal computer-worker Runtime.

## Production contract

- Production is an immutable compiled release supervised by launchd.
- Development/source changes do not replace or restart Production.
- Production changes only through the explicit `npm run promote:production` boundary.
- Computer MCP 1.x remains standalone/legacy-backed; OWL Runtime is not a 1.x production dependency.
- Primitive ABI v1, Skill ABI v1, Session Adapter v1, Embedding Provider v1, and Workspace Lease v1 are stable with additive 1.x compatibility.

## Daily-use stability

1.0 includes bounded MCP request/resource waits, logical owner identity across transport rotation, stale-session reclamation, durable process ownership, process-tree cancellation, workspace lease recovery, graceful drain/handoff, immutable release rollback, versioned durable state, and fault-recovery receipts.

The macOS Native Helper has an independent lifecycle. Normal Server promotion does not rebuild or replace `~/Applications/Computer MCP Helper.app`, preserving its path, Bundle ID, binary identity, and macOS TCC grants.

## Permissions and first-run experience

1.0 adds persistent access profiles:

```bash
npm run permissions:status
npm run permissions:standard
npm run permissions:full-home
```

Fresh installs without a project `.env` receive a usable standard user-folder profile. `full-home` is intended for an explicitly trusted personal-worker installation.

ChatGPT onboarding is consolidated under:

```bash
npm run setup
```

Tunnel credentials remain outside Git, the API key is passed through a `file:` reference, and the final ChatGPT Plugin/Tunnel authorization remains an explicit user action.

## Release evidence

The frozen release passed the complete short-form release gate: typecheck/build, ABI/contracts, Task/Scheduler/Loop/Memory, session adapters, macOS Helper syntax, concurrency, stability core, real MCP transport rotation/cancellation, drain/handoff, state schema, fault recovery, recovery matrix, production boundary, Performance P0, resource waits, tunnel, onboarding, permissions profiles, fresh immutable release, Production Runtime verification, and smoke soak.

The smoke soak completed with zero independent action errors, zero managed-process failures, no nonterminal Tasks, no running-process leak, no workspace-lease leak, and healthy session/WeChat adapter fixtures.

## Long-soak qualification

The 2-hour, 6-hour, and 24-hour soak profiles exist but have not been claimed as completed release evidence here. They remain post-release qualification evidence. This release does not fabricate those results.

## Upgrade and rollback

Upgrade from an existing 0.9.x Production goes through candidate preflight, graceful drain, state-schema compatibility validation, immutable symlink cutover, post-cutover health verification, and automatic rollback to the previous immutable release if the new release fails health verification.
