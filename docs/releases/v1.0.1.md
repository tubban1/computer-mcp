# Computer MCP 1.0.1

Computer MCP 1.0.1 is the production-install reliability patch for the 1.0 line.

## Fixes

- Production first-install / legacy-cutover now retries launchd bootstrap with a bounded retry loop.
- If LaunchAgent registration still fails, the installer restores the previous immutable release symlink before aborting and attempts to restore the previous service.
- Production Runtime verification now reads the expected version from `package.json` instead of hard-coding a release string.

## Compatibility

No Runtime ABI, Skill ABI, Session Adapter, Embedding Provider, Workspace Lease, state-schema, or Native Helper identity changes are introduced. The 1.x standalone production architecture remains unchanged.

## Upgrade

A healthy 1.0.0 installation should upgrade through the normal explicit boundary:

```bash
npm run promote:production
```

The candidate is preflighted, the current Runtime is drained, the immutable release symlink is switched, and post-cutover health is verified.
