# Roadmap to AgentOS Runtime 1.0

Current baseline: **v0.9.11**

The core execution Runtime is feature-complete enough to enter production-hardening mode. 1.0 should prioritize invariants, recovery, compatibility, and long-duration reliability over adding more feature surfaces.

## 1. Production service baseline — DONE

- [x] compiled `dist` Runtime
- [x] immutable release directories
- [x] launchd supervision
- [x] production/development/test state isolation
- [x] health verification
- [x] install-time rollback with rollback health verification
- [x] active-release self-mutation guard

## 2. Session-aware concurrency baseline — DONE

- [x] execution context
- [x] action-scoped workspace Resource Arbiter locks
- [x] hierarchical parent/child conflicts
- [x] sibling workspace concurrency
- [x] Task-scoped durable ownership
- [x] Process-scoped durable ownership
- [x] Transaction-scoped durable ownership
- [x] persistent process metadata/logs
- [x] recovered/disconnected process claim
- [x] orphan session lease reclamation

## 3. Graceful drain / wait / takeover / handoff — NEXT

Target: **v0.9.12**

- [ ] Runtime state: RUNNING → DRAINING → STOPPED
- [ ] stop accepting new mutating work while draining
- [ ] wait for in-flight actions to reach safe boundaries
- [ ] `runtime.workspace wait`
- [ ] explicit takeover request
- [ ] graceful Task/workspace handoff
- [ ] handoff audit receipt
- [ ] no silent lease stealing

## 4. Upgrade protocol / blue-green Runtime

Target: **v0.9.12–0.9.13**

- [ ] start candidate Runtime on alternate port/socket
- [ ] validate providers/state compatibility
- [ ] drain old Runtime
- [ ] switch routing/current release
- [ ] shut down old Runtime
- [ ] automatic rollback when candidate fails
- [ ] upgrade integration verifier

## 5. Durable state schema and migration

Target: **v0.9.13**

- [ ] global state schema/version registry
- [ ] migration registry
- [ ] forward compatibility policy
- [ ] backup before incompatible migration
- [ ] migration dry-run/status command
- [ ] per-store schema ownership
- [ ] documented code rollback vs state rollback rules

## 6. Recovery and fault-injection matrix

Target: **v0.9.13**

- [ ] crash during filesystem mutation
- [ ] crash during Git transaction
- [ ] crash while managed process runs
- [ ] crash during scheduler wake
- [ ] crash during loop phase
- [ ] crash during browser-agent send
- [ ] crash during WeChat send
- [ ] crash during semantic promotion
- [ ] crash during workspace handoff
- [ ] restart recovery verifier

## 7. Multi-agent soak

Target: **v0.9.14**

- [ ] multiple chats on independent repositories
- [ ] competing writes to same repository
- [ ] background scheduler + loops
- [ ] browser-agent session relay
- [ ] WeChat polling
- [ ] 2-hour soak
- [ ] 6-hour soak
- [ ] 24-hour soak
- [ ] deadlock/lease/PID/memory leak checks
- [ ] duplicate-side-effect checks

## 8. ABI and contract freeze

Target: **v1.0.0-rc.1**

- [ ] Primitive ABI 1.0 freeze
- [ ] Skill ABI 1.0 freeze
- [ ] Session Adapter Contract 1.0
- [ ] Embedding Provider Contract 1.0
- [ ] Workspace Lease Contract 1.0
- [ ] deprecation policy
- [ ] 1.x backward-compatibility statement
- [ ] conformance tests for every Primitive family

## 9. Release gate

- [ ] all release checklist items pass
- [ ] no known critical concurrency/recovery defect
- [ ] production install/upgrade/rollback tested
- [ ] docs navigation complete
- [ ] fresh-machine setup tested
- [ ] 24-hour soak clean
- [ ] `v1.0.0-rc.1` observed before final `v1.0.0`
